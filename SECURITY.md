# Security

Report a vulnerability through a GitHub private security advisory on this repository:

https://github.com/rade-nugroho/protege/security/advisories/new

Do not open a public issue for a vulnerability.

Describe what is affected, how to reproduce it, and the impact. This repository has no security contact address, PGP key, bug bounty, or response-time commitment.

The engine listens on `127.0.0.1`. Keep tokens and connector secrets in the environment or Infisical, and keep them out of git, logs, mapping files, and evidence.
