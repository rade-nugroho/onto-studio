# Security

## Report a vulnerability

Send an undisclosed vulnerability by email to the project maintainers named in the `developers` section of `pom.xml`:

- matthew.horridge@stanford.edu
- csongor.nyulas@stanford.edu
- tredmond@stanford.edu
- tudorache@stanford.edu
- vendetti@stanford.edu

Do not open a public GitHub issue for an undisclosed vulnerability. Do not post it to the protege-user or protege-dev mailing lists.

This repository does not publish a separate security address.

## What to include

- The affected Protégé version
- Steps to reproduce the problem
- The impact, including what an attacker could do

## What happens next

A maintainer will review the report and reply. The project does not publish a response-time commitment.
